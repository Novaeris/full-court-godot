# V2.1 reference player and comparison scene

`compare_<view>.png`: the same reference player (key `reference:1`, 2.01 m, 100 kg, SF, skin tone 4, fade, goatee, face 3) rendered by `tools/reference_scene.gd` with identical cameras, lighting and poses for: the procedural default, M1 (rejected), V2.0 and the V2.1 reference. Views: front, side, back, face, upper body, hands, shoes, neutral pose, action pose (jump shot).
Folders `proc/`, `m1/`, `v2_0/`, `v21/` hold the single images; `roster/` shows the V2.1 improvements on the generated roster (showcase and portraits).
Rendered in Godot (the game renderer), not in Blender, so every improvement shown is in the game.
