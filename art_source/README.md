# Art source (D-076)

`players/fc_master_player.blend` is THE master Full Court player: the artistic source of truth for the 3D player. Stored with Git LFS.

- **Never regenerated by script.** `tools/blender/master/create_master.py` made it once (from the V2.1 generator) and refuses to run again.
- **Exports never write it.** `tools/blender/master/export_master.py` opens it read-only, writes `assets/players/v2/fc_v2_body.glb` and `parts/fc_v2_parts.glb`, and fails if the master's SHA-256 changed.
- **Every change is backed up first.** Modeling passes save through `master_lib.save_master(label)`, which copies the previous master to `players/versions/` (also LFS) before writing.
- **Morphs survive edits.** Every mesh carries the body (`fcb_`) and face (`fcf_`) morph targets as shape keys; move geometry with `master_lib.move_vertices()` (same offset in every key) or, by hand in Blender, edit with "Shape Key Edit Mode" care.
- **Modular collections:** FC_Rig, FC_Body, FC_Head, FC_Uniform, FC_Shoes (body file) and FC_Hair, FC_Facial, FC_Equipment (part file).
- **Approval gate:** after every pass, `tools/blender/master/render_master.py` (Blender) and `tools/reference_scene.gd` (Godot, the real game) render the same views; a pass is accepted only when the game pictures improve.

This folder has a `.gdignore`: Godot never imports it.
